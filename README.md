# 🚀 Running the Projects

## Python

```bash
cd Python
python -m venv .venv

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# macOS / Linux / Git Bash
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

## JavaScript

```bash
cd JavaScript

npm install
node app.js
```

# 🔐 Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
OPENAI_API_KEY=your_api_key
GOOGLE_API_KEY=your_api_key
```

> **Important:** Never commit your `.env` file or API keys to Git. They are ignored using `.gitignore`.
